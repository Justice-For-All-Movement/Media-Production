# Retained output permissions

`getRenderOutput` (including `manifest.json`) and `getExportBytes` treat each byte read as a new reproduce use. Stored render/export decisions and unblocked event flags are not fresh permission. The caller context, actor roles, capabilities and compartments are copied/frozen before awaits; capability, stored scope/compartment and an optional current AuthorizationPort are checked. These copies are not authentication or original-human delegation.

Before object retrieval and before returning bytes, the engine obtains strict literal allow decisions for the retained render's actual input versions and declared sources, using newest asset-rights metadata. Rejected/blocked assets deny. Unknown/review/exception denies, including preview reads. Asset permission refs/sources already included in their groups are not silently discarded; remaining declared non-E10 sources get their own group. Old permission refs retained in the render remain obligations when rights change. This checks recorded groups, not source completeness or independent source truth. Empty-source original work has no external decision group. Explicit standalone declared-rights still marks its unchecked behavior; it is not production permission proof.

Each admission rereads render and asset metadata after the external decision. Exact render/input/source/output/manifest and asset-rights bases must match throughout the sequential before/after read checks. Export reads also retain the original recorded audience/destination and exact export metadata. No caller can substitute a broader audience. Stored output byte counts/hashes and the manifest's canonical JSON digest are verified. The ObjectStore must return Uint8Array bytes; a fresh independent copy prevents Buffer alias mutation during later callbacks. There is one object read and no automatic retry, render, export command, lease or use permit. Authorization callback errors are sanitized.

Read failures retain all render/export records, original decisions, stored bytes and history. Metadata APIs such as getRenderManifest/getRender/getExport and other asset/QC/preview paths keep their existing semantics; this change qualifies only the two byte-read methods and their existing HTTP routes. Current policy may change after the final check, including during later SQL reads. These sequential snapshots are not an atomic distributed permission fence and cannot revoke previously delivered copies. Remote decision/audit writes may commit when bytes are withheld or acknowledgements are lost; no rollback or quiescence is inferred. No E11 recordUse is issued.
